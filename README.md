Flappy Bird Remake

A faithful recreation of the classic Flappy Bird, built from scratch in Unity using C#. This project was built to practice core 2D game development fundamentals - physics-based movement, procedural obstacle spawning, collision detection, and game state management.

Features

Tap/click-based flap mechanic with gravity and momentum
Procedurally spawning pipe obstacles with randomized gaps
Collision detection and game-over state
Score tracking as the player passes through pipes
Restart/replay flow

Built With

Unity - game engine
C# - gameplay scripting

What I Learned

I had never used Unity before starting this project, so it doubled as a crash course in the engine itself, not just the game logic. Along the way I learned:

Unity fundamentals: the editor workflow, scenes, GameObjects, and the component-based architecture
C# scripting: writing MonoBehaviours and hooking scripts up to GameObjects
Rigidbody physics: using gravity and forces to drive the bird's movement instead of hand-rolling motion math
Sprites: importing and configuring 2D art assets for animation and rendering
Triggers/collisions: detecting pipe collisions and score triggers without full physical collision response

Going from zero Unity experience to a finished, playable game was the real challenge of this project.
